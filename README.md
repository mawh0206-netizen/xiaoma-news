# 小马看世界

个人每日新闻工作台。每天北京时间08:00启动生产、08:30前完成发布与公众号草稿，聚焦AI、科技、企业商业、财经、房地产、国内外汽车产业与国际要闻。公众号日更栏目为“每日汽车透视”。

## 接手项目先读

- 换电脑、新会话或修改生产流程前，先完整阅读 [`START_HERE.md`](START_HERE.md)。
- 汽车行业权威数据源、统计口径和解读细则见 [`EDITORIAL_DATA_GUIDE.md`](EDITORIAL_DATA_GUIDE.md)。
- `START_HERE.md` 是长期规则的唯一总入口；自动化记忆只用于追溯历史，不替代仓库文档。

## 内容原则

- 国际核心来源：Reuters、BBC、Financial Times、The Guardian、TechCrunch。
- 国内核心来源：第一财经、财联社、证券时报、36氪、澎湃新闻、界面新闻、经济观察报，以及盖世汽车、中国汽车报、中国汽车流通协会等垂直媒体与行业机构。
- 仅展示中文标题、短摘要、AI 决策提示、来源和原文链接，不复制媒体全文。
- 首页约 20 条必读，栏目页保留更多候选内容。
- 栏目配额：AI/科技/企业商业/财经至少 8 条，房地产、汽车金融与国际要闻至少 6 条，汽车产业至少 10 条；首页仍保持约 20 条，控制晨读负担。
- 每日主任务08:00启动，08:30为硬截止；08:15巡检补救，08:25仍未成功必须告警。
- 抓取或发布失败时保留上一版，并通过本机现有 QQ SMTP 配置发送异常邮件。
- 公众号行业解读优先使用协会、监管、政府和企业法定披露的原始数据；完整来源目录、口径说明和“活人感”编辑门禁见 [`EDITORIAL_DATA_GUIDE.md`](EDITORIAL_DATA_GUIDE.md)。

## 公众号编辑复核

- 固定栏目名为“每日汽车透视”，观点模块为“小马观察”；“汽车行业晨报”和“产品经理解读”均为停用名称。

- 08:00 主任务负责生成新闻事实、数据线索与公众号草稿；事实和来源必须可追溯。
- 08:15 发布巡检除日期、线上状态和封面品牌检查外，还应抽查/改写公众号解读：每条先找反常点，再补最相关的数据与背景，给出有条件的预判。
- 公众号正文逐条保留新闻来源，但不展示“今日/昨日”和具体发布时间；`publishedAt`与`publishedLabel`继续保留在内部数据中，用于自然日时效门禁与审计。
- 不要求所有解读采用相同结构；同期相同开头、结尾和指标组合应视为质量问题。
- 公开事实不足、只能生成泛化评论的选题应优先替换；无法替换时明确说明证据不足，不强行判断。
- 选题先过质量门槛再排序：政策/监管/安全与行业拐点优先，权威数据和重大经营变化其次，量产技术与重点产品再次；仅标题、奖项申报、概念异动、泛投融资周报和弱相关内容原则上淘汰。完整规则见 [`EDITORIAL_DATA_GUIDE.md`](EDITORIAL_DATA_GUIDE.md)。
- 汽车集团财报是A级重点来源；优先解读销量与收入、汽车分部EBIT/毛利率、现金流和库存之间的背离，关键口径必须回到交易所或公司投资者关系原文。
- 编辑更新只覆盖当天同一篇草稿，不新建、不群发。

`data/news.json` 是网站唯一的内容入口。自动任务生成新内容后覆盖该文件并触发静态部署。
